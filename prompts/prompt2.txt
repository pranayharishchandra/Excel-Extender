I want to build a production-quality desktop application in Python for extending Excel formulas in SAP material creation templates.

This is NOT just a Python script.
Treat it like a real desktop application with clean architecture, modular code, and an extensible design.

==================================================
PROJECT GOAL
==================================================

I have SAP material creation Excel workbooks.

The workbook contains:

- Sheet1 (user input)
- Multiple formula sheets (Sheet2, Sheet3, Sheet4, PIR, etc.)

The user ONLY edits Sheet1.

All other sheets contain formulas referencing Sheet1.

Originally these templates were created for only around 10 materials.

I have already converted every formula into fully draggable formulas using Excel functions such as:

- ROW()
- MOD()
- INT()
- INDEX()
- etc.

The formulas already behave exactly like Excel AutoFill.

The Python application's only responsibility is extending those formulas to any number of materials.

Never modify the formulas themselves.

==================================================
TECHNOLOGY
==================================================

Python

openpyxl

CustomTkinter

Use

from openpyxl.formula.translate import Translator

for all formula translation.

Never manipulate formulas manually.

Never use regex.

Never replace row numbers yourself.

Always use Translator.
